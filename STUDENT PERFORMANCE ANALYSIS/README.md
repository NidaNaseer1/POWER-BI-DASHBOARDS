# Student Performance Analysis 📊

## 📌 Project Overview
This project focuses on analyzing student academic performance using SQL and Power BI. The main objective is to identify factors influencing student performance and understand the relationship between study time, previous failures, gender, and final grades.

## 🛠️ Tools & Technologies
- MySQL
- MySQL Workbench
- Power BI
- DAX

## 📂 Dataset Information
- Dataset: Student Performance Dataset
- Source: UCI Machine Learning Repository
- Total Records: 395
- Columns: 33

## 🧹 Data Cleaning
- Checked for duplicate records.
- Handled text formatting using TRIM and UPPER.
- Prepared the dataset for analysis.
- Connected MySQL database to Power BI.

## 📊 Dashboard Highlights

### Key Performance Indicators (KPIs)
- Total Students
- Pass Percentage
- Average Final Grade
- Passed Students
- Failed Students

### Visualizations
1. Pass vs Fail Students
2. Average Grade by Previous Failures
3. Gender-wise Student Distribution
4. Average Final Grade by Gender
5. Average Grade by Study Time
6. Student Distribution by Study Time
7. Student Performance Analysis using different visualizations

### Interactive Filters
- Gender
- Study Time
- Age

## 🔍 Key Findings
- Total students: 395
- Passed students: 265
- Failed students: 130
- Pass percentage: 67.09%
- Overall average final grade: 10.42
- Male students have a slightly higher average final grade than female students.
- Students with more previous failures tend to have lower final grades.
- The 2–5 hours study-time group has a higher student count.

## 💡 Recommendations
- Provide additional academic support to struggling students.
- Encourage consistent study habits.
- Identify students with previous failures and provide individual guidance.
- Conduct regular assessments to monitor student progress.
- Introduce personalized learning strategies.

## 🎯 Project Outcome
This project demonstrates how SQL and Power BI can be used to clean, analyze, and visualize student data to generate meaningful insights and support data-driven educational decisions.
